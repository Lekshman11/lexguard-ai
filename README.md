# LEXGUARD AI 🛡️
AI-powered legal risk detection and virtual legal assistance system for educational and awareness purposes.

## Features
- 📄 Document Scanner & Risk Detection
- ⚖ Virtual Legal Advisor (Indian Law, Educational Use)
- 📚 Past Case Matcher
- 👨‍⚖ Lawyer Connect
- 🚨 Protect Me (Voice Emergency Mode)
